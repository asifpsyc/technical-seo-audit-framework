# Technical SEO Audit Framework

A repeatable framework for identifying, classifying, and prioritizing
technical SEO issues across websites.

## Includes

- Crawl issue categorization
- Impact and effort scoring
- Indexation checklist
- Core Web Vitals review
- Internal linking review
- Sample audit output

## Example outcome

The framework helps SEO teams move from a long list of crawl errors
to a prioritized action plan for developers and content teams.

## Best for

SEO managers, agencies, content teams, and website migrations.
